# 小厨宝

一个完全离线的 AI Passport 菜谱参考应用。固件里带着 340 道社区收集的家常菜——
菜名、配料行、编号步骤，以及 177 张实拍封面图——不联网、不发起 HTTP、不访问文件
系统。开机后要么直接给你推荐一道菜，要么进入可翻阅的菜谱列表。屏幕上的标题是中文
名「小厨宝」，本档案用 Little Kitchen Pal 指代它。

本页是设计与实现档案；按键操作、设置项与已知限制见
[使用说明](USER_GUIDE.zh_CN.md)；按日期记录的改动见
[更新日志](CHANGELOG.zh_CN.md)。

## 功能

- **开机直达**：不注册演示菜单，启动即进入应用。
- **随机推荐**：每次抽一道菜，显示封面、菜名与品类。短按确定键换一道。
- **分类页**：340 道菜按源数据的目录顺序分成 15 个品类，每行显示品类名与该品类的
  菜谱数。「进入菜谱」先落到这一页。
- **菜谱列表**：只列当前品类里的菜谱，短按走一行，长按翻一屏。翻页与选中逻辑和
  分类页共用同一份代码，两页手感完全一致。
- **菜谱详情**：三个子页——封面与菜名、配料、步骤。长按上下键在子页之间切换；短按
  把当前子页整页翻一屏，翻到最后一屏再按一下就进入下一个子页。
- **封面按需解码**：177 张实拍图打包成两个预烘焙的基线 JPEG 数据块。LVGL 内置的
  tjpgd 按行解码，整帧数据永远不会落进 RAM。
- **电量显示**：右上角，每 5 秒刷新，低于 20% 变红。电量计不可用时显示 `--`，
  而不是编一个数字。
- **设置页**：亮度（25 / 50 / 72 / 100%）与息屏时间（关闭、30 秒、1 分钟、
  5 分钟、10 分钟），两项都存进 NVS，断电不丢。
- **关于页**：项目名、版本、作者，以及菜谱数据、字体与息屏逻辑的来源。
- **息屏**：无操作满设定时长先关屏（背光灭、面板 Sleep In、停止刷屏），再过 5 秒
  让 ESP32-C3 反复进入 light sleep，只留一个每 120 毫秒一次的轮询等按键。任意按键
  唤醒，回到息屏前正在看的那一页。
- **按键提示条**：只出现在首页、分类页、列表页与设置页底部；随机页、详情页与关于
  页把这块高度让给内容。

## 交互

- **上/下 短按**：首页 = 切换两个按钮；分类页与列表页 = 移动一行；详情页 = 正文翻
  一屏；设置页 = 切换条目；关于页 = 滚动正文。
- **上/下 长按**：分类页与列表页 = 翻一屏；详情页 = 在三个子页之间切换。
- **确定 短按**：首页 = 进入选中项；随机页 = 看这道菜的做法；分类页 = 进入该品类的
  列表；列表页 = 打开菜谱；设置页 = 调整选中项。
- **确定 长按**：首页 = 进设置页；随机页、分类页与设置页 = 回首页；列表页 = 回分类
  页；详情页 = 回进来时的那一页；关于页 = 回设置页。
- **息屏中**：第一下按键只唤醒，不执行任何动作。

## 数据与占用

| 项 | 大小 |
| --- | --- |
| 菜谱 | 340 道，分 15 个品类 |
| 参与随机的菜谱 | 279 道 |
| `.rodata` 中的菜谱文案 | 117,795 字节（约 115 KiB） |
| 带封面的菜谱 | 340 道中 177 道 |
| `main/assets/covers_large.bin` | 1,125,031 字节（200 x 150） |
| `main/assets/covers_small.bin` | 698,243 字节（144 x 108） |
| 三个中文字体子集 | 748,352 + 1,097,787 + 122,589 字节 |

能塞进去的关键在字符清单这一步：三个中文字形子集只收录 987 个汉字加可打印 ASCII，
而按三个字号整套打包 Noto Sans SC 是装不下的。

## 起决定作用的设计取舍

- **用 JPEG 而不是原始位图。** 一张 200 x 150 的 RGB565 原始封面是 60KB，177 张就是
  10MB。基线 JPEG 把同一批图压到 1.1MB，而 tjpgd 按 MCU 行输出，解码只需约 4KB
  工作缓冲，而不是一整帧。
- **两档尺寸在打包阶段烘焙。** 运行时缩放需要把整帧解码结果放进 RAM，在无 PSRAM 的
  芯片上放不下，所以改由资源脚本预先生成 200 x 150 与 144 x 108 两档。
- **随机池是独立的表。** 上游数据里 40 条配料（酱料、锅底、卤油）与 21 条瓶装饮品
  在结构上也是"菜谱"，但它们不是菜。它们仍然出现在列表页里，只通过生成的索引表从
  随机推荐中排除，因此不会抽到「农夫山泉矿泉水」。
- **页面与按键状态机不依赖 LVGL 与 ESP-IDF。** 页面切换、列表窗口计算与随机选取都能
  在主机上编译运行，因此有不需要真机的测试覆盖。
- **封面描述符在多个槽位间轮转。** 切页重写 `lv_image_dsc_t` 时，LVGL 渲染任务可能
  还在读它；四个轮转槽位消除了这个窗口。
- **待机页不做，低功耗要做。** 早先的版本会先显示 30 秒「休息中」待机页再关背光，
  而那类待机页通常要显示时间——这块板子没有可信的时钟来源，画出来只会是错的，
  所以整页去掉。但要真省电，光关背光不够：CPU 还在全速跑、面板自身还在耗电。
  于是改成关屏之后再进 light sleep，并用 `iot_button_stop()` 停掉按键组件那个
  每 5 毫秒一次的轮询定时器——不停它，light sleep 会被掐成 5 毫秒一段，等于白睡。
  用 light sleep 而非 deep sleep，是因为唤醒后要原样回到刚才那一页（deep sleep
  等于重启），而且三个按键共用一路 ADC 分压，「上」键按下时的电压仍在数字输入的
  低电平阈值之上，没有可靠的 GPIO 唤醒源，只能定时读电压。
- **配料与步骤的行首标记靠重着色，不靠多一个控件。** 每行只有一个标签，文本以
  `#RRGGBB` 行内命令开头，于是圆点或序号是橙色、正文是墨色，却不必为每行多加一个
  对象——这里的 LVGL 堆只有 48 KB。代价是菜谱正文里不能出现 `#`，这条约束由
  `tests/test_cook_assets.py` 守住。
